## Структура проекта
- `Assets/Scripts/` — весь игровой код.
  - `Core/` — базовые системы (сервисы, события, DI).
  - `Gameplay/` — игровая логика.
  - `UI/` — интерфейс.
- `Assets/Prefabs/`, `Assets/Scenes/`, `Assets/Art/` — ресурсы.
- `Packages/manifest.json` — зависимости проекта.

## Правила кода
- Стиль: PascalCase для классов и методов, camelCase для локальных переменных, `_camelCase` для приватных полей.
- Поля для инспектора: `[SerializeField] private`, а не `public`.
- Не использовать `Find`, `FindObjectOfType` и `GetComponent` в `Update`. Кэшировать ссылки в `Awake` или `Start`.
- Избегать аллокаций в `Update` (строки, LINQ, `new` для коллекций).
- Один класс на файл, имя файла совпадает с именем класса.
- Комментарии к публичным методам, сложную логику поясняй кратко.

## Что НЕЛЬЗЯ трогать
- Папки `Library/`, `Temp/`, `Logs/`, `obj/`, `UserSettings/`.
- Файлы `.meta`: не удалять, не создавать и не править вручную.
- Файлы сцен (`.unity`) и префабов (`.prefab`) не редактировать напрямую. Если нужна правка, объясни, что сделать в редакторе Unity.
